# REQUIREMENTS.md

The record of what was agreed, and why the code exists.

## Why this file

An audit of this repo in August 2026 misattributed ~545 lines as "no traceable
requirement" — a fifth of everything it flagged. Those features had been asked
for in conversation. Chat leaves no trace in the repo, so anything that reads
only the repo concludes the code was invented.

**Every agreed requirement lands here before it is implemented.** If a
requirement is not in this file, the next audit is entitled to call it
unrequested and delete it. That includes requirements agreed verbally: write
them down here first, then build.

One line per requirement. Say what and why, not how. Link to the milestone.
Mark status honestly — `built`, `agreed`, `cut`, `deferred`.
