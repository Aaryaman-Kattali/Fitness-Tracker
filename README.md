# fitness_tracker

Single-user Android fitness app in the iOS visual language. Offline-first, side-loaded, no backend.

`CLAUDE.md` how to work here · `REQUIREMENTS.md` what was agreed · `PROGRESS.md` what happened and what was learned · `NOTES.md` open questions · `ARCHITECTURE.md` stack and schema.

Flutter is not on PATH: `$env:PATH = "E:\src\flutter\bin;" + $env:PATH`

Then `flutter test` and `flutter build apk --debug`.

`captures/` holds ground-truth GPS recordings. Each one cost a walk and none can be regenerated.
